01
Challenge & Autonomous Geospatial Vision

Traditional mapping of rapidly urbanizing regions like Kabupaten Tangerang (~1,193 km²) requires hundreds of hours of manual remote tracing. Human digitizers face high cognitive fatigue, subjective boundary placement, and prolonged turnaround times.

LandAssist solves this with a foundation-model pipeline that converts 64-band multispectral embeddings into topologically regularized, vector-clean OpenStreetMap polygons served directly to mappers in real time.

02
End-to-End Deep Learning & Vector Pipeline
Stage 1 • Acquisition
Earth Engine 64-Band GSE
Partitions AOI into 4 sub-tiles (mitigating GEE 48 MB limit), acquiring annual Sentinel-2 latent embeddings at 10m ground resolution.
Stage 2 • Segmentation
SegFormer MiT-B2 Inference
Custom 64-input patch stem with 2D Hann window blending over disk memory-mapped buffers. Fast GPU T4 batched execution (~2 min).
Stage 3 • Regularization
GDAL Sieve & Chaikin Curvature
Eliminates noise (< 1,600 m² MMU) and applies Chaikin corner-cutting in UTM Zone 48S (EPSG:32748) to smooth pixel-step staircase artifacts.
Stage 4 • Vector Ingestion
PostGIS & FastAPI Vector Tiles
Streamed ingestion into Supabase PostGIS with GIST indexing; served over REST GeoJSON and Mapbox Vector Tiles (MVT) with CORS.
03
OSM Landuse Taxonomy & Class Mapping

LandAssist models strictly output OpenStreetMap-compliant attribute tags with lineage tracking (source=LandAssist_v1.0.0;GSE):

Background
class=0

Vegetation, water bodies, agriculture, open rural land.

Industrial
landuse=industrial

Warehouses, manufacturing plants, industrial estates.

Residential
landuse=residential

High & medium density settlements, villages, suburban blocks.

04
Standalone Web Editor (Render Cloud 24/7)

LandAssist hosts a standalone, customized Rapid/iD Web Editor deployed in the cloud. Mappers can visualize predicted polygons seamlessly overlaid on real-world high-resolution satellite basemaps.

Key Editor Capabilities:
  • Automatic Bounding Box querying via spatial REST API
  • Single-click conversion into editable OSM polygon features
  • Preset OSM tagging with verified confidence scores
  • Zero local environment or GIS software installation needed
